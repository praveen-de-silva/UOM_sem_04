# CS3513 RPAL Lab Practical

This project contains eight RPAL programs, each designed to demonstrate various programming concepts using the RPAL language. Below is a brief description of each program included in this project.

## File Descriptions

1. **1.txt**: 
   - This program checks whether a given number is positive or negative. It uses conditional expressions to evaluate the number and return 'Positive' or 'Negative'.

2. **2.txt**: 
   - This program finds the greatest of three numbers. It compares the three numbers using conditional expressions and returns the largest one.

3. **3.txt**: 
   - This program prints the Fibonacci series within a specified range. It uses a loop to generate Fibonacci numbers until the upper limit is reached.

4. **4.txt**: 
   - This program calculates the factorial of a given number. It uses recursion to compute the factorial value.

5. **5.txt**: 
   - This program checks if a given number is a palindrome. It compares the number with its reverse to determine if they are the same.

6. **6.txt**: 
   - This program displays all palindrome numbers within a specified range. It iterates through the range and checks each number for the palindrome condition.

7. **7.txt**: 
   - This program checks if a number is odd or even. It uses the modulus operator to determine the parity of the number.

8. **8.txt**: 
   - This program calculates the sum of the first n natural numbers. It uses a loop to accumulate the sum from 1 to n.

## Running the Programs

To run the RPAL programs, ensure you have the RPAL Interpreter installed. You can execute each program by providing the corresponding file name as an argument to the interpreter.

## Additional Information

For any issues or questions regarding the programs, please refer to the documentation of the RPAL Interpreter or contact the course instructor.
